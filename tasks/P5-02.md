Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Workbooks go out and come back without manual file handling, and every return re-runs grouping.

**Build**
- **S3 layout** in `dp-lake-<acct>`: `validation/outbox/<cycle_id>/<app>.xlsx` and `validation/inbox/<cycle_id>/<app>.xlsx`.
- **Step Functions `dp-sfn-validate`**
  1. Generate workbooks into the outbox.
  2. Write a manifest.
  3. Publish an SNS message to `dp-validation` with presigned GET URLs valid for 7 days. The PoC channel is email to the operator, who forwards the files.
- **Inbox trigger**: an EventBridge rule on `Object Created` under `validation/inbox/` invokes `parse.py` for that file, then starts `dp-sfn-resolve-enrich` from the grouping step onward, with the latest `run_id`.
- **Escalation**: a scheduled daily Lambda applies the escalation rule.

**Acceptance**
- [ ] Running `dp-sfn-validate` puts workbooks in the outbox and sends the SNS message.
- [ ] Uploading a filled test workbook to the inbox updates `validation_state` and re-runs grouping.
