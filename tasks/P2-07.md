Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** One library every collector uses, so collectors contain only source-specific logic.

**Build.** Python package `dp_collect`:
- **`Collector` base class.** Subclasses implement `domain`, `name`, `version`, `regional: bool`, and `collect(ctx) -> Iterator[Record]`.
- **Session and regions**
  - `ctx.session(region)`: boto3 session for `dp-collector`. Standard retries with adaptive mode.
  - Region fan-out over `HOME_REGION`, `SECOND_REGION` and `DENIED_REGION` when `regional`.
  - `AccessDenied`, `UnauthorizedOperation` and similar errors on a region or API become a `record_kind=coverage` record with `reason=access_denied`. The run continues.
- **Pagination.** `ctx.paginate(client, op, **kw)` wraps boto3 paginators and also supports manual token loops.
- **Checkpoints**
  - `ctx.checkpoint.get/put(scope, value)` on `dp-checkpoints`.
  - Incremental sources (CloudTrail, flow logs, Actions runs, Jenkins builds) store the last processed marker.
- **Redaction, before anything is written.** Raw is Object Lock-protected, so a secret written there cannot be deleted.
  - Module `dp_collect.redact`. Collectors declare `sensitive_paths` (JSONPath) per resource type. Detectors also scan every string value:
    - AWS access key ID pattern `(AKIA|ASIA)[A-Z0-9]{16}`
    - `CONDOR-CANARY-[0-9a-f-]{36}`
    - private key PEM headers
    - GitHub token prefixes `gh[pousr]_`
    - strings of 32 or more characters with Shannon entropy ≥ 4.0 under keys matching `(?i)(secret|token|password|passwd|api_?key|credential)`
  - Each hit is replaced with `{"redacted": true, "detector": "<name>", "sha256": "<hash of value>"}`.
  - Each hit also emits an `event` record with `resource_type=DP::Redaction` and payload `{source_resource_id, json_path, detector, sha256}`. This is the evidence for AK-APP-03.
- **Writer**
  - Batches records into JSON Lines, gzip, at most 50 MB per part, at the raw key layout in `CLAUDE.md` section 7.
  - Computes `payload_sha256` over canonical JSON (sorted keys, no whitespace).
  - Validates each record against `raw-envelope.schema.json`. Invalid records fail the run.
- **Ledger**: writes to `dp-run-ledger` a start row, then an end row with record counts per `record_kind`, coverage counts, duration, status, and error summary.
- **Scope**: `ctx.is_platform(tags)` returns true for `managed-by=discovery-platform` or anything in `platform/scope/exclusions.yaml`. Collectors still record platform resources; the flag goes in `payload.dp_scope = "excluded"`.
- **Logging**: structured JSON logs with `run_id`, `collector` and `region`. A redacting log filter drops any field whose key matches `(?i)(secret|token|password|key)$`.
- **Lambda handler factory**: `make_handler(CollectorClass)`, with event `{ "run_id": optional, "regions": optional }`.
- **Terraform module `collector`**: inputs `name`, `source_dir`, `timeout`, `memory`. Creates the function (Python 3.12, arm64) in `collector` subnets with `dp-collector` role, log group with 30-day retention, and platform tags.
- Unit tests for `redact`: every detector has positive and negative cases, and redacted output never contains the input value.
- **Test helper `dp_collect.testing.query_raw(run_id, collector, predicate)`**: reads a run's part files straight from `dp-raw` and yields matching records. Collector integration tests use it, so they never depend on Athena.
- **Example collector `hello`**: lists S3 buckets. A unit test asserts one resource record per bucket and one coverage record for `DENIED_REGION` from a moto-mocked denial.

**Acceptance**
- [ ] `pytest platform/collectors/framework` passes offline.
- [ ] After deploy, invoking `hello` writes one part file, and the ledger shows `status=succeeded` and a coverage count of 1.
