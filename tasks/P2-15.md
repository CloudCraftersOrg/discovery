Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Jobs, builds, plugins and credential references from the Jenkins controller, read-only, over the private estate link.

**Build.** Domain: `pipelines`. Base URL `http://jenkins.condor.internal:8080`, with the token from `dp/jenkins/reader`.
- **Controller**: version from the `X-Jenkins` header; nodes and executors from `/computer/api/json`; plugins from `/pluginManager/api/json?depth=1` (short name, version, active).
- **Plugin advisories**: fetch `https://updates.jenkins.io/update-center.actual.json` through the egress path. Match installed plugin versions against the `warnings` entries. Emit a `resource` record per matched warning.
- **Jobs**: tree `/api/json?tree=jobs[name,url,_class,jobs[name,url,_class]]`, recursive for multibranch. `config.xml` per job.
- **Builds** since checkpoint: `number`, `result`, `timestamp`, `duration`, `causes`, and SCM revision from `actions` (lastBuiltRevision SHA).
- **Credentials**: IDs, types and descriptions from the credentials API. No secret fields. If the plugin exposes none without admin rights, emit `coverage` with `reason=access_denied`.
- **Jenkinsfile**: for multibranch jobs, record the repo and branch. The GitHub collector already has the file contents.
- If the controller is unreachable, emit a `coverage` record with `reason=unreachable` and succeed.

**Acceptance**
- [ ] Unit tests with recorded JSON and XML fixtures, including the unreachable path.
- [ ] Integration:
  - Two jobs found.
  - The `facturacion-nightly-export` config.xml is present and contains `ssm send-command`.
  - At least one plugin warning matched.
  - Builds since `history_start` present.
