Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Turn on every data source the platform depends on, before the estate exists, so history starts accumulating early.

**Read first.** `CLAUDE.md` sections 3 and 4.

**Build.** Terraform, applied as `condor-bootstrap`. Every resource carries only the tag `managed-by=cloud-governance` (AK-GRP-10).
- **AWS Config**
  - Recorder and delivery channel in `HOME_REGION` and `DENIED_REGION`, recording all supported resource types. Delivery bucket `condor-config-<acct>`. No `SECOND_REGION` recorder (ADR-044-network-consolidation) — nothing is deployed outside `HOME_REGION` and the `DENIED_REGION` canary, so a third recorder would just report empty.
  - Configuration aggregator in `HOME_REGION`, source: this account, all regions.
- **CloudTrail**
  - Trail `condor-trail`: multi-region, management events read and write, delivered to bucket `condor-trail-<acct>`.
  - Data events for S3 `PutObject` and `DeleteObject` on bucket `condor-tfstate-<acct>` only.
  - If an organization trail already exists, keep this trail anyway. The collector reads this bucket.
- **CUR 2.0**: a Data Exports export `condor-cur2` to bucket `condor-cur-<acct>`: Parquet, daily, with resource IDs.
- **Cost allocation tags**: activate `app` and `managed-by`, through the Billing API if permitted.
- **Opt-in**: Cost Optimization Hub and Compute Optimizer enrollment for this account.
- **Flow logs bucket**: `condor-flowlogs-<acct>`. The VPCs attach to it in P1-04.
- **Quick**: do not create the subscription. Write the operator steps in `tasks/HANDOFF-P1-03.md`.

**Acceptance**
- [ ] `aws configservice describe-configuration-recorder-status --region <r>` shows recording for both regions (`HOME_REGION`, `DENIED_REGION`).
- [ ] `aws cloudtrail get-trail-status --name condor-trail` shows `IsLogging: true`.
- [ ] `aws bcm-data-exports list-exports` lists `condor-cur2`.
- [ ] `aws cost-optimization-hub get-enrollment-status` shows `Active`.
- [ ] `aws compute-optimizer get-enrollment-status` shows `Active`.

**Out of scope.** Cloud Intelligence Dashboards (P2-06).

**Stop and ask if** any of these fail because of Organization-level restrictions: CUR export from this account, cost allocation tag activation, Cost Optimization Hub enrollment, or Compute Optimizer enrollment. Do not work around them.
