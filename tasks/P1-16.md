Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Confirm the estate has produced enough data for the platform to be tested against. Nothing in Phase 4 can pass before this.

**Build** `estate/verify/check_ready.py`. Passes only when all are true:
- `check_planted.py --only P1-13` and `--only P1-14` pass.
- CUR 2.0 has delivered at least one partition containing Tienda resource IDs.
- Compute Optimizer returns a recommendation for the Tienda ASG.
- Cost Optimization Hub returns at least one recommendation for this account.
- Flow logs contain accepted flows Tienda → Pagos NLB, worker → Reportes ALB, Inventario → Tienda RDS.
- Harness ledger has ≥ 8 commits and each of Tienda, Pagos, Reportes has ≥ 2 completed pipeline runs after `history_start`.
- `answer-key/expected/dora.json` exists.

**Acceptance**
- [ ] `uv run estate/verify/check_ready.py` exits 0. If not, print each unmet condition and stop. Do not sleep-loop; the operator re-runs the task later.
