# P2-04 · Collector identities

| Field | Value |
|---|---|
| Phase | Phase 2 · Build the collectors |
| Stream | I |
| Depends | P2-01, P1-07, P1-11, P1-05 |
| Gate | `human-action` |

Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Every read-only credential the collectors need, and nothing more.

**Build**
- **IAM role `dp-collector`**, trusted by the Lambda service only.
  - Managed policies: `ReadOnlyAccess`, plus `AWSCloudTrail_ReadOnlyAccess` if needed.
  - Inline allows:
    - `s3:GetObject` and `s3:ListBucket` on `condor-cur-<acct>`, `condor-flowlogs-<acct>`, `condor-trail-<acct>`, `condor-config-<acct>`, `condor-tfstate-<acct>`.
    - `s3:GetObjectVersion` and `s3:ListBucketVersions` on `condor-tfstate-<acct>`.
    - `s3:PutObject` on `dp-raw-<acct>`.
    - Writes to `dp-run-ledger` and `dp-checkpoints`.
    - `secretsmanager:GetSecretValue` on `dp/*` only.
    - `eks:DescribeCluster` on `condor-pagos`.
  - Explicit denies:
    - Every action in `DENIED_REGION`, through `aws:RequestedRegion` (PLANTED: AK-COV-01).
    - Every read on `condor-harness-ledger-<acct>`.
    - `secretsmanager:GetSecretValue` on `condor/*`.
    - `ssm:GetParameter*` with decryption, and `ecs:ExecuteCommand`.
  - Permissions boundary: `dp-collector-boundary`, which denies all write actions except the listed S3, DynamoDB and ledger writes.
- **EKS**: access entry for `dp-collector`, associated with `AmazonEKSViewPolicy`, cluster scope.
- **Jenkins**: copy the `dp-reader` token into `dp/jenkins/reader`.
- **GitHub**: a GitHub App `dp-discovery-reader` with read-only repository permissions for contents, metadata, actions, administration (for branch protection), Dependabot alerts and secrets metadata. Installed on the four app repos only, never `condor-harness`. Store its app ID, installation ID and private key in `dp/github/app`.

**Human action.** Creating and installing the GitHub App needs an org owner. Write exact steps and the permissions list in `tasks/HANDOFF-P2-04.md`.

**Acceptance**
- [ ] A test invocation as `dp-collector` can call `ec2:DescribeInstances` in `HOME_REGION` and gets `AccessDenied` in `DENIED_REGION`.
- [ ] `ec2:RunInstances` is denied everywhere.
- [ ] Authenticating to EKS and running `kubectl get deployments -A` works; `kubectl get secrets -A` is forbidden.
- [ ] Jenkins `/api/json` with the stored token returns 200.
- [ ] GitHub App installation token lists exactly four repos.
