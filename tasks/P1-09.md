Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** A legacy Windows and SQL Server workload identified only by a tag.

**Build**
1. **Resolve the AMI first.** Find an AWS-provided Windows Server 2016 + SQL Server **2019 or 2022** Standard license-included AMI still launchable in `HOME_REGION`. Record the AMI ID and name in the PR. SQL Server 2016 and 2017 are not acceptable: their end-of-support dates would create lifecycle findings that are not in the answer key. If no acceptable AMI exists, stop and ask.
2. **EC2 `condor-facturacion`**
   - Instance type: the smallest the AMI supports. Record its hourly price.
   - Placed in the `app` subnets.
   - Instance profile with SSM core only.
   - Tag `app=facturacion` only (PLANTED: AK-GRP-04).
3. **License Manager**: let AWS's automated license-included discovery run. Do not create license configurations here; P2-06 handles License Manager.
4. **No pipeline, no alarms** (PLANTED: AK-PIP-11, AK-APP-04).
5. Append IDs to `manifest.json`.

**Acceptance**
- [ ] The instance is SSM-managed.
- [ ] `aws ssm list-inventory-entries --type-name AWS:Application` shows SQL Server.

**Cost limit.** USD 1.50/hour. **Stop and ask if** the cheapest supported size exceeds it.
