Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Prove every answer-key item has raw evidence before any processing is built.

**Build**
- **`platform/tests/contract/test_envelope.py`**: samples 1,000 records per collector from the latest run through the `dp_lake.raw_records` external table (P3-03). Each must validate against the envelope schema, have a `domain` matching `collectors.yaml`, and have a `payload_sha256` that recomputes.
- **`answer-key/trace/source_queries.yaml`**: for each answer-key item, one or more Athena queries over raw data, all of which must return ≥ 1 row proving the evidence exists.
  - Example: AK-PIP-02 needs a CloudTrail `PutImage` by `dev.juan` after `history_start`.
  - Items checked only after processing (`kind: metric`, `business_case`, `quality`) carry only their source-presence queries.
- **`answer-key/trace/run_source_trace.py`**: runs all queries and prints item → pass/fail.

**Acceptance**
- [ ] The contract tests pass.
- [ ] `run_source_trace.py` passes for every item. Any item failing means a collector gap: open a blocking issue naming the collector.
