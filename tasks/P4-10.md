**Goal.** Proof that every derived output is reproducible from raw data alone.

**Build.** Script `platform/tests/replay/run_replay.py`, run on demand and in CI nightly:
1. Snapshot the mart outputs (`mart_*`) to `dp-lake/replay/before/` as sorted CSV.
2. Truncate all Aurora canonical tables except `schema_migrations` and `validation_state`. Drop all Iceberg derived tables except `stg_records`. Re-create them empty through P3-03's Terraform-managed definitions or dbt.
3. Re-run `dp-sfn-resolve-enrich` for the same set of `run_id`s.
4. Export the marts again, diff byte for byte, and ignore only columns listed in `platform/tests/replay/volatile_columns.yaml` (generated UUIDs and `recorded_at`). The UUIDs must be deterministic, `uuid5` from natural keys, so the list should be nearly empty.

- [ ] The replay diff is empty (AK-QLT-02).
