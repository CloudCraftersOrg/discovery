Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Prove every planted condition exists, independently of the platform, and mark the moment history starts.

**Build**
- `estate/verify/refs.json`: logical name → real ID or ARN for every `resource_ref` in the answer key, generated from Terraform outputs, stack outputs and `manifest.json`. Commit the generator, `make refs`, and its output.
- `estate/verify/check_planted.py [--only <task-id>]`: one check per answer-key item whose `planted_by` is a Phase 1 task, calling AWS, GitHub and Jenkins APIs directly as `condor-bootstrap`. Output: table of ID, pass/fail, detail. Exit non-zero on any fail.
  - Items planted by P1-13 and P1-14 are skipped unless `--only` names them.
  - Checks that need accumulated data (flows, recommendations, CUR rows) belong in P1-16, not here.
- On first fully passing run, write `estate/verify/history-start.json` `{"history_start": "<UTC ISO-8601>"}`. Bootstrap activity before this moment is excluded from DORA and manual-deploy detection.

**Acceptance**
- [ ] `uv run estate/verify/check_planted.py` exits 0.
- [ ] `history-start.json` committed.
