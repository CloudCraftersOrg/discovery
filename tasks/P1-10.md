Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** An untagged app whose grouping comes from its runtime primitives, plus a worker attachable only through flow logs.

**Build.** CLI scripts. Append all IDs to `manifest.json`.
- **Launch template and ASG `condor-reportes`**
  - Amazon Linux 2023, `t3.small`, desired 2, `app` subnets.
  - Java 17, CodeDeploy agent and SSM Agent installed.
  - No user tags.
- **Load balancing**: internal ALB `condor-reportes`, target group attached to the ASG, record `reportes.condor.internal`.
- **CodeDeploy**
  - Application `condor-reportes`, deployment group targeting the ASG.
  - Artifact bucket `condor-reportes-artifacts-<acct>`, untagged.
- **EC2 `condor-reportes-worker`**
  - Amazon Linux 2023, `t3.micro`, no tags.
  - Cron job calling `reportes.condor.internal/report` every minute.
  - After boot, stop and disable the SSM Agent through user data (PLANTED: AK-COV-02).
- **No alarms** (PLANTED: AK-APP-04).

**Acceptance**
- [ ] Both ASG instances are healthy in the target group.
- [ ] Worker requests appear in flow logs. Check with Athena or S3 Select on the flow logs bucket.
- [ ] The worker is absent from `aws ssm describe-instance-information`.

**Cost limit.** USD 0.15/hour.
