Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Freeze every schema the rest of the platform depends on. Human reviewers from both streams sign off before merge.

**Read first.** `CLAUDE.md` section 7, `answer-key/answer-key.yaml`.

**Build**
- **`docs/contracts/raw-envelope.schema.json`**: exactly the envelope in `CLAUDE.md` section 7. `payload` is an open object. Add conditional requirements: if `record_kind=coverage`, then `payload.reason` is required, with the listed enum.
- **`docs/contracts/collectors.yaml`**: the registry of every collector name used in the answer key. For each:
  - `domain`
  - `resource_types`
  - cadence: `daily`, `hourly` or `on_delivery`
  - `regional`: bool
  - `evidence_for`: answer-key IDs
  - Validate that every collector named in the answer key appears.
- **`docs/contracts/canonical-model.md`**, plus `platform/db/migrations/0001_init.sql` for Aurora PostgreSQL. Tables:
  - `run(run_id, started_at, finished_at, status)`
  - `entity(entity_id uuid, entity_type, natural_key, first_seen, last_seen)`
    - `entity_type` enum: `resource`, `application`, `pipeline`, `repository`, `identity`, `image`, `platform_tooling`, `governance`, `shared_infrastructure`
  - `identity_link(link_id, entity_id, key_type, key_value, tier smallint, confidence numeric)`
    - `key_type` enum: `arn`, `instance_id`, `ssm_node_id`, `resource_id`, `ip`, `eni`, `hostname`, `image_digest`, `pod_uid`
  - `assertion(assertion_id, entity_id, attribute, value jsonb, source, confidence, observed_at, recorded_at, valid_from, valid_to, run_id)`: bitemporal
  - `relation(relation_id, from_entity, to_entity, relation_type, confidence, source, valid_from, valid_to)`
    - `relation_type` enum: `member_of`, `depends_on`, `deploys_to`, `built_from`, `runs_image`, `operational_automation`, `managed_by_iac`
  - `evidence(evidence_id, derived_table, derived_id, raw_s3_uri, raw_line, payload_sha256)`
  - `source_precedence(signal, confidence)`: seeded with the ladder in `CLAUDE.md` section 7
  - `adjudication(item_id, kind, candidates jsonb, status, decided_by, decided_at)`
  - `validation_state(entity_id, app_entity_id, status, response jsonb, workbook_version, row_hash, updated_at)`
    - `status` enum: `issued`, `confirmed`, `corrected`, `reassigned`, `partial`, `no_response`, `escalated`, `signed_off`
  - `finding(finding_id, rule_id, entity_id, severity, value_usd, band_low, band_expected, band_high, band_assumption, realization_lag_days, evidence_ids uuid[], run_id)`: all value columns `NOT NULL`
- **`docs/contracts/finding-rule.schema.json`**: the rule catalog entry format, with fields `rule_id`, `domain`, `description`, `inputs`, `logic_ref`, `severity`, `monetization_ref` and `answer_key_ids`. All are required except `answer_key_ids`, which is PoC grading metadata: a client engagement has no answer key, so a schema that demands one cannot express a rule for a real estate. Every rule in this repository still carries it, asserted by `P4-07` rather than by the schema.
- **`docs/contracts/transform-handoff.schema.json`**: the handoff package contract. Placeholder structure with `applications[]`, `business_case`, `modernization_candidates[]` and `evidence_index`, finalised in P5-05.
- **ADRs**, numbered from 037, each one page: context, decision, consequences.
  - **037:** single account and single environment for the PoC.
  - **038:** dbt-athena for transforms; Aurora for the canonical model through the Data API; canonical tables exported back to Iceberg for dashboards.
  - **039:** a private ECR repo `dp-dbt` exists only for the dbt Lambda image. This corrects the earlier "no ECR" statement.
  - **040:** egress invariant. An IGW exists for NAT; no workload subnet routes to it; all egress passes Network Firewall. This corrects the earlier "no internet gateway" statement.
  - **041:** estate link through VPC peering and Resolver endpoints (details from P2-03).
  - **042:** the Pagos self-hosted runner is shared platform tooling.
