# P2-02 · Controlled egress

| Field | Value |
|---|---|
| Phase | Phase 2 · Build the collectors |
| Stream | I |
| Depends | P2-01 |
| Gate | `approve-apply` |
| Paths | platform/terraform/egress/ |

Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Collectors reach GitHub, and nothing else outside AWS.

**Build**
- **NAT gateway**: one, in a `nat` subnet.
- **AWS Network Firewall `dp-egress`**: endpoints in the `firewall` subnets.
  - Stateful domain allowlist (TLS SNI and HTTP host): `github.com`, `api.github.com`, `codeload.github.com`, `objects.githubusercontent.com`, `updates.jenkins.io`, `www.jenkins.io`, plus any AWS domains recorded in ADR-040.
  - Default action: drop established; alert.
  - Flow and alert logs to CloudWatch log group `/dp/network-firewall`.
- **Routing**: `collector` → firewall endpoint → NAT → IGW. Add the IGW ingress route table for return traffic to the firewall endpoint. `data` subnets unchanged.
- **Test Lambda `dp-egress-probe`**: HTTPS GET to `api.github.com` must succeed; to `example.com` must fail.

**Acceptance**
- [ ] Invoking `dp-egress-probe` returns `{"github": "ok", "example": "blocked"}`.
- [ ] The firewall alert log shows the `example.com` drop.

**Cost limit.** USD 0.60/hour.
