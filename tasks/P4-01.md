Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** The database, transform runtime and orchestration that every Phase 4 task plugs into.

**Build**
- **Aurora PostgreSQL Serverless v2 cluster `dp-canonical`**
  - Placed in `data` subnets. Security group allows no inbound traffic; access is through the Data API only.
  - Capacity 0.5 to 2 ACU, KMS `dp-db`, Data API enabled, master secret managed by RDS in Secrets Manager under `dp/`.
- **Migrations**: Lambda `dp-migrate` applies `platform/db/migrations/*.sql` in order through the Data API, tracked in table `schema_migrations`.
- **dbt image**
  - Private ECR repo `dp-dbt` (ADR-039): immutable tags, scan on push.
  - Container image for Lambda: Python 3.12 base image, dbt-core, dbt-athena, and the `platform/dbt` project.
  - Lambda `dp-dbt` runs `dbt build --select <selector>` from its event, with a 900 s timeout and 3,008 MB memory.
- **Aurora → Iceberg export**: Lambda `dp-export-canonical` copies `entity`, `relation`, `assertion` (current rows only), `finding` and `validation_state` into their Iceberg tables for a `run_id` by paginated Data API reads and batched Athena inserts, or through S3 Parquet plus `INSERT ... SELECT`. Choose and document one.
- **Step Functions `dp-sfn-resolve-enrich`**, input `{run_id}`. Each step is a Task invoking the Lambda from its task; P4-01 wires placeholders that return success.
  1. `dp-dbt` selector `staging`
  2. `dp-identity` (P4-02)
  3. `dp-grouping` (P4-04)
  4. `dp-dependencies` (P4-05)
  5. `dp-pipeline-link` (P4-06)
  6. `dp-grouping` again, second pass, so confirmed pipeline deploy targets become grouping signals
  7. `dp-rules` (P4-07, P4-08)
  8. `dp-monetize` (P4-09)
  9. `dp-export-canonical`
  10. `dp-dbt` selector `marts`
- **Chaining**: the ingest stage (P3-02) invokes this state machine at the end of every daily cycle.

**Acceptance**
- [ ] `dp-migrate` applies `0001_init.sql`, and a re-run is a no-op.
- [ ] `dp-dbt` with selector `coverage` succeeds.
- [ ] `dp-sfn-resolve-enrich` with placeholders completes.

**Cost limit.** USD 0.25/hour at minimum capacity.
