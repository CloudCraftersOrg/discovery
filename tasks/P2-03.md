# P2-03 · Private path to the estate

| Field | Value |
|---|---|
| Phase | Phase 2 · Build the collectors |
| Stream | I |
| Depends | P2-01, P1-07, P1-11 |
| Gate | `approve-apply` |
| Paths | platform/terraform/estate-link/ |

Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Collectors reach the Pagos EKS private API and Jenkins, and nothing else inside the estate.

**Revised for ADR-044 (one VPC).** There is no `dp-discovery` VPC to peer with `condor-estate` — both are subnets of the single `condor-vpc` (P1-04). That removes everything cross-VPC this task used to need: no VPC peering, no cross-VPC private-zone association, no Resolver inbound/outbound endpoint pair. `condor.internal` is already associated with `condor-vpc`; a Lambda in the `collector` subnet resolves it through the VPC's own built-in resolver like anything else in the VPC. Record this in `docs/adr/ADR-041-estate-link.md`, which now describes this shape, not the pre-consolidation one.

**Build**
- **Security group rules**, managed by platform Terraform using separate `aws_vpc_security_group_ingress_rule` resources with platform tags. Do not edit estate Terraform.
  - EKS cluster security group: 443 from `dp-collector`'s CIDRs.
  - `condor-jenkins` security group: 8080 from the same CIDRs. (Note: P1-11 already opens 8080 from the whole `condor-vpc` CIDR, `10.20.0.0/16` — this rule narrows that to just the collector subnets rather than leaving the broader one as the only path in.)
  - These rule resources are platform resources and excluded from scope.
- **Test Lambda `dp-estate-probe`**: resolve and TCP-connect to the EKS endpoint on 443 and to `jenkins.condor.internal:8080`. Also try `tienda.condor.internal:80`, which must fail.

**Acceptance**
- [ ] The probe returns `{"eks": "ok", "jenkins": "ok", "tienda": "blocked"}`.

**Stop and ask if** the EKS endpoint hostname does not resolve from the `collector` subnet. Do not make the endpoint public.

**Cost limit.** USD 0.02/hour — was 0.30/hour before ADR-044; the Resolver endpoint pair this task used to create (~$0.25/hr) no longer exists.
