# P1-11 · Jenkins controller

Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** A realistic neglected Jenkins that deploys Reportes and runs an automation job defined only inside Jenkins.

**Build**
- **Terraform**, state key `jenkins/terraform.tfstate`:
  - EC2 `condor-jenkins`: Amazon Linux 2 AMI (PLANTED: AK-INF-05), `t3.medium`, `app` subnets.
  - Separate EBS volume mounted at `/var/lib/jenkins` (`JENKINS_HOME`). No AWS Backup plan and no snapshot policy (PLANTED: AK-INF-06).
  - Instance profile with `AdministratorAccess` plus `condor-sandbox-boundary` (PLANTED: AK-PIP-05).
  - Security group: port 8080 from `10.20.0.0/16` only. Record `jenkins.condor.internal`.
  - No tags.
- **Jenkins install**, through user data or an SSM document:
  - An LTS release at least four LTS lines behind current, with Java 17 (PLANTED: AK-PIP-10). Record the versions.
  - Executors on the controller: 2. No agents (PLANTED: AK-PIP-10).
  - One plugin pinned to a version with a published Jenkins security advisory (PLANTED: AK-PIP-10). List the plugin, version and advisory ID in the PR. **Gate:** a human approves the choice before apply.
  - Plugins required: git, workflow-aggregator, pipeline-aws or equivalent, credentials, and configuration-as-code if needed.
  - Read-only user `dp-reader` with Overall/Read, Job/Read, Job/ExtendedRead (needed for `config.xml`) and Credentials/View (IDs only). Use the matrix-auth plugin. Store its API token in Secrets Manager `condor/jenkins/dp-reader`. P2-04 later copies the reference.
- **Jobs**, created through the Jenkins REST API by scripts in `estate/clickops/jenkins-jobs/`:
  - `condor-reportes`: multibranch pipeline on `condor-reportes`, polling every 5 minutes.
    - Its Jenkinsfile runs `mvn package`, uploads to the artifacts bucket, then `aws deploy create-deployment` to `condor-reportes`.
    - No test stage and no `input` step (PLANTED: AK-PIP-06).
  - `facturacion-nightly-export`: a freestyle job whose XML exists only in Jenkins, never committed (PLANTED: AK-PIP-07).
    - Shell step: `aws ssm send-command --targets Key=tag:app,Values=facturacion` running a PowerShell export of a dummy table.
    - Cron `H 2 * * *`.
    - Uses Jenkins credential `aws-facturacion-export`, which holds the static keys of IAM user `svc.jenkins-export` (PLANTED: AK-PIP-04). That user's policy allows `ssm:SendCommand` on Facturación only, with the boundary.
  - Commit the job-creation script, but put the XML for `facturacion-nightly-export` in `estate/clickops/jenkins-jobs/.private/`, gitignored. The script reads it from there.

**Acceptance**
- [ ] From the runner or a Tienda instance: `curl jenkins.condor.internal:8080/login` returns 200.
- [ ] A push to `condor-reportes` triggers a build that creates a CodeDeploy deployment.
- [ ] Triggering `facturacion-nightly-export` manually succeeds, and the SSM command shows `Success`.

**Cost limit.** USD 0.10/hour.
