Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** What runs, what it is made of, how it is exposed, and whether it is monitored.

**Build.** Domain: `apps`.
- **`ssm_inventory`**
  - Managed instances.
  - Inventory types: `AWS:Application`, `AWS:InstanceInformation`, `AWS:Service`, `AWS:WindowsRole`, `AWS:Network`.
  - For any EC2 instance in the latest `config` run that is not SSM-managed, emit `coverage` with `reason=unreachable` and `payload.gap="ssm_not_managed"` (AK-COV-02, AK-COV-04).
- **`ecs_taskdefs`**
  - Every active task definition revision in use: container images, ports, log config, environment variable **names**, and secret references.
  - Environment variable values are declared as `sensitive_paths`, so the framework redacts them before writing. Non-secret values survive redaction only if no detector fires; the canary token must not.
- **`kubernetes`**
  - Authenticates to `condor-pagos` with an EKS token generated from the `dp-collector` role through the private endpoint.
  - Lists namespaces, deployments, statefulsets, daemonsets, services, ingresses, and pods (including `imageID` digests and labels), plus Helm release metadata from annotations and labels.
  - Never lists Secrets.
- **`route53`**: private and public hosted zones with records.
- **`param_secret_meta`**: Parameter Store parameter names, types and tiers without values; Secrets Manager secret names, tags and last-accessed dates. Never calls `get_parameter` or `get_secret_value`.
- **`cloudwatch_alarms`**: alarms with dimensions; log groups with retention and stored bytes.

**Acceptance**
- [ ] Unit tests: `ssm_inventory` emits coverage for a fixture instance absent from SSM; `param_secret_meta` code contains no call to value APIs (enforced by an AST test); `ecs_taskdefs` on a fixture with the canary emits a redacted payload and one `DP::Redaction` event.
- [ ] Integration:
  - The `pagos` deployment and its image digest are present.
  - Coverage records exist for `reportes-worker` and `promo-2024-instance`.
  - Alarms exist for Tienda and Pagos and none for the other apps.
