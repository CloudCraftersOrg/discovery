**Goal.** Owners confirm or correct the proposed portfolio at scale, through spreadsheets, not a portal.

**Build**
- **Spec `docs/specs/validation.md`**
  - **One workbook per proposed application.** Also one `unassigned.xlsx` workbook for ungrouped resources, addressed to the executive sponsor.
  - **Sheet `Members`**
    - Visible columns: resource name, type, ID, monthly cost, membership source, confidence, `Decision`, `Reassign to app`, `Comment`.
    - `Decision` is a dropdown with values `Confirm`, `Not mine`, `Reassign`, `Decommission OK`, `Keep`.
    - Hidden protected columns: `entity_id`, `app_entity_id`, `workbook_version`, `row_hash`. The row hash is sha256 over entity ID, app entity ID, version and the visible pre-filled cells.
  - **Sheet `Application`**: owner name, owner email, criticality (`Tier 1` to `Tier 3`), SLA, on-call contact, runbook URL. Pre-fill the owner from CODEOWNERS where available.
  - **Sheet `Findings`**: the app's findings with value, band and a `Response` dropdown with values `Accept`, `Dispute`, `Already known`.
  - **Sheet protection**: all sheets protected except the input columns. The protection password is stored in `dp/validation/sheet-password`. This is a tamper guard, not security.
  - **Return parsing**
    - Rows whose hash doesn't match are rejected and reported.
    - `Confirm` sets `validation_state` to `confirmed`. `Reassign` sets `reassigned` and writes `relation(member_of)` to the target app, confidence 1.0, source `owner_validation`.
    - `Not mine` sets `corrected`. The resource is removed from the app; if it now has no membership it goes to the unassigned workbook next cycle.
    - Blank decisions count as `no_response`. When some but not all rows in a workbook are answered, the workbook is `partial`.
    - `Decommission OK` in `unassigned.xlsx`, from the sponsor, sets `signed_off`.
  - **Escalation**: resources still `no_response` after `validation.sla_days` (default 5) move to `escalated` and are added to `unassigned.xlsx`.
- **Implementation**: `platform/validation/workbooks/generate.py` and `parse.py`, using `openpyxl`, both reading and writing Aurora through the Data API.

**Acceptance**
- [ ] Unit tests:
  - generate, then parse an untouched workbook: every row is `no_response`
  - a tampered hash is rejected
  - a reassignment writes the relation
  - a partial workbook is detected
- [ ] Workbooks generate for every estate app plus `unassigned.xlsx`, and open in Excel and LibreOffice without repair prompts.
