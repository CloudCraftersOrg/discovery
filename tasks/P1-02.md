Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** A machine-readable list of everything the platform must find, with the evidence each item must be proven by. Every later test runs against this file.

**Read first.** `CLAUDE.md` sections 4 and 7. Every Phase 1 task.

**Build**
- `answer-key/schema.json`, JSON Schema for items with these fields:
  - `id`: pattern `AK-[A-Z]{2,3}-[0-9]{2}`
  - `domain`: `infra`, `apps`, `pipelines`, `coverage`, `business_case` or `quality`
  - `kind`: `grouping`, `dependency`, `finding`, `link`, `metric`, `coverage`, `validation` or `business_case`
  - `subject`: object with any of `app`, `resource_ref`, `pipeline_ref`
  - `expect`: object
  - `evidence_sources`: list of collector names, at least one
  - `planted_by`: task ID
  - `checked_in_phase`: 2 to 5
  - `tolerance`: optional object
  - `resource_ref`: a logical name such as `reportes-worker`, resolved to a real ID by `estate/verify/refs.json`, which P1-15 generates
- `answer-key/answer-key.yaml`, containing exactly the items below. Do not add or remove items without a PR marked `answer-key change`.
