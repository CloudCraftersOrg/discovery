Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** The first thing shown in any engagement: what was reached, what was not, and why.

**Build.** dbt models on `dp_lake`, run locally with dbt-athena for now. The Lambda image arrives in P4-01.
- **`coverage_reach`**: per run, domain, collector and region: `status` (`reached`, `denied`, `unreachable`, `throttled`, `unsupported`), record counts, and gap reasons.
- **`coverage_resource_gaps`**: per in-scope resource, missing sources. For example, an EC2 instance with no `ssm_inventory` record gets `ssm_not_managed`.
- **`coverage_summary`**: per domain, the percentage of in-scope resources with complete expected sources, where the expected sources per resource type come from `collectors.yaml`.
- **dbt tests**: `not_null` and `accepted_values` on status. A custom test `denied_region_present` asserts `DENIED_REGION` appears with status `denied` (AK-COV-01).
- **`answer-key/trace/processed_checks.yaml`**: add the coverage checks for AK-COV-01 to AK-COV-04 as Athena queries over these models.
