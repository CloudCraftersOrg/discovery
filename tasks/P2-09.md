Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Runtime, data store and resilience configuration for every in-scope resource.

**Build.** Domain: `infra`. Regional unless noted.
- **`ecs`**: clusters, services (with deployments, task definition ARN, network config), and task sets. Task definitions are collected by the apps collector `ecs_taskdefs`, not here.
- **`eks`**: clusters with version, platform version, endpoint access config, node groups, add-ons, and access entries.
- **`elb`**
  - Load balancers, listeners and rules, and target groups.
  - Target health, with instance IDs or IPs.
  - Emits `relation(member_of)` from target group to target.
- **`asg`**: groups with instance IDs, launch template references, and attached target groups.
- **`rds`**: DB instances and clusters with engine and version, extended support status if the API exposes it, parameter groups and their non-default parameters, backups, replicas, and endpoints.
- **`backup`**: backup plans, selections and protected resources.
- **`ebs`**: volumes with attachment state, snapshot counts and latest snapshot time per volume, and Data Lifecycle Manager policies.

**Acceptance**
- [ ] Unit tests with fixtures for each collector.
- [ ] Integration: raw data shows Reportes target-group membership for both ASG instances, the EKS version for `condor-pagos`, zero snapshots for the Jenkins home volume, and `condor-pagos-params` with the drifted `max_connections`.
