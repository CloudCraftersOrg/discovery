Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** The discovery platform's private network and storage, isolated from the estate.

**Read first.** `CLAUDE.md` sections 5 and 6.

**Build.** Terraform, state in `dp-tfstate-<acct>`, applied as `dp-deployer`. Platform tags on every resource via `default_tags`.
- **VPC `dp-discovery`**, CIDR `10.90.0.0/16`, two AZs. Subnets per AZ:
  - `collector`, private: Lambda functions.
  - `data`, isolated: no route beyond the VPC. Holds Aurora later.
  - `firewall`: Network Firewall endpoints (P2-02).
  - `nat`, public: NAT gateway (P2-02).
- **Internet gateway**: attached to the VPC. Only `nat` subnets route to it. Add a Terraform `check` block that fails if any `collector` or `data` route table has a route to the IGW.
- **Interface endpoints** in `collector` subnets, private DNS enabled: `sts`, `logs`, `ssm`, `secretsmanager`, `kms`, `glue`, `athena`, `states`, `lambda`, `rds-data`, `config`, `cloudtrail`, `ec2`, `ecs`, `eks`, `elasticloadbalancing`, `autoscaling`, `codepipeline`, `codebuild`, `codedeploy`, `ecr.api`, `monitoring`, `tagging`, `iam` if available in region, `backup`, `license-manager`, `compute-optimizer`, `cost-optimization-hub`, `wellarchitected`, `route53` if available.
  - For any service with no VPC endpoint in `HOME_REGION`, record it in `docs/adr/ADR-040-egress-exceptions.md`. Those calls go through the firewall path; add the AWS domain to P2-02's allowlist.
- **Gateway endpoints**: `s3`, `dynamodb`.
- **KMS**: customer-managed keys `dp-raw`, `dp-lake`, `dp-db`, `dp-secrets`, each with rotation on.
- **S3**
  - `dp-raw-<acct>`: versioned; Object Lock enabled at creation, default governance mode, 30 days; SSE-KMS with `dp-raw`; public access blocked; TLS-only bucket policy.
  - `dp-lake-<acct>`: versioned; SSE-KMS with `dp-lake`.
  - `dp-athena-results-<acct>`: SSE-KMS; lifecycle 7 days.
- **DynamoDB**
  - `dp-run-ledger`: PK `run_id`, SK `collector#region`, on-demand.
  - `dp-checkpoints`: PK `collector#region#scope`, on-demand.
- **Security groups**: `dp-collector` with egress only to the VPC CIDR, the S3 prefix list, and `0.0.0.0/0` on 443. The 443 rule is safe because routing forces all internet traffic through the firewall.

**Acceptance**
- [ ] `terraform plan` shows no changes after apply.
- [ ] The `check` block passes.
- [ ] Uploading an object to `dp-raw` and then trying to delete that version fails because of Object Lock.

**Cost limit.** USD 0.90/hour. Interface endpoints dominate; state the count and cost in the PR.
