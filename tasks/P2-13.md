Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Repositories as both app evidence and pipeline evidence.

**Build.** One Lambda with two logical outputs:
- **App records** (`domain=apps`, `source=github_code`), per installed repo:
  - Languages.
  - Default branch.
  - Dependency manifests found (`requirements*.txt`, `pyproject.toml`, `package.json`, `package-lock.json`, `pom.xml`): paths and parsed direct dependencies.
  - Dependabot alerts: package, version range, advisory ID, severity.
  - CODEOWNERS contents.
- **Pipeline records** (`domain=pipelines`, `source=github`):
  - Branch protection on the default branch.
  - Workflow files, raw YAML plus path.
  - Workflow runs since checkpoint: `id`, `head_sha`, `event`, `status`, `conclusion`, `run_started_at`, `updated_at`, `runner labels`.
  - Commits on the default branch since checkpoint: `sha`, `author date`, `committer date`.
  - Actions secret **names**.
  - Environments with protection rules.
- **Authentication**: GitHub App installation token. Handle rate limits with backoff, honouring `x-ratelimit-reset`.

  - Dependabot alerts present for Tienda and Reportes.
  - Pagos branch protection present.
  - Runs since `history_start` present.
