# P2-08 · Infra collectors: inventory and IaC

| Field | Value |
|---|---|
| Phase | Phase 2 · Build the collectors |
| Stream | I |
| Depends | P2-07 |
| Gate | `none` |
| Paths | platform/collectors/infra/ |

Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Every resource, its configuration and tags, and whether IaC manages it.

**Build.** One Lambda per collector, built on `dp_collect`. Domain: `infra`.
- **`config`**
  - Uses the aggregator: `select_aggregate_resource_config` for all resource types, all regions.
  - Emits `resource` records with configuration and supplementary configuration.
  - Emits `relation` records from Config relationships.
  - Also emits a daily `event` summary per resource: count of configuration changes in the last 30 days, from `get_aggregate_resource_config` history or configuration item timestamps.
- **`tagging`**: Resource Groups Tagging API `get_resources`, per region. Emits tags per ARN. Also lists Resource Groups.
- **`cloudformation`**: per region, stacks including `DELETE_COMPLETE` from the last 90 days, stack resources with physical IDs, and drift status if detection was ever run. Emits `relation(member_of)` records from stack to resource.
- **`tfstate`**
  - Lists every object ending `.tfstate` in `condor-tfstate-<acct>`.
  - Parses Terraform state v4 and emits `resource` records `{address, type, provider, attributes_subset}`, where the subset is only ID-like attributes: `id`, `arn`, `name`, `identifier`.
  - Never emits sensitive attributes. Drop any attribute marked sensitive in state, and any key matching the redaction regex.
  - Emits `relation(managed_by_iac)` from state file to resource ID.
- **`organizations`**: `describe_organization`, and `describe_account` for this account only. If access is denied (member account), emit coverage records and continue.

**Acceptance**
- [ ] Unit tests with fixtures cover:
  - a Config select page
  - a CloudFormation stack with 3 resources
  - a Terraform state with a sensitive attribute, which must be absent from the output
  - an Organizations access-denied response
- [ ] Integration test (`-m aws`): after a run, `dp_collect.testing.query_raw` returns the Tienda stack's resources, the Pagos state resources, and zero tfstate records with keys matching the redaction regex.
