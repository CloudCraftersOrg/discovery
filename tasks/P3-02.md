# P3-02 · Staging and contract gate

| Field | Value |
|---|---|
| Phase | Phase 3 · Gather and store |
| Stream | I |
| Depends | P3-01, P3-03 |
| Gate | `none` |
| Paths | platform/processing/stage/, platform/terraform/orchestration/ |

Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Only valid, deduplicated, secret-free records reach the lakehouse.

**Build**
- **Step Functions `dp-sfn-stage`**, input `{run_id}`.
  1. **Validate**: re-validate every part file for this run against the envelope schema. Invalid parts move to `quarantine/engagement=<e>/run_id=<r>/` in `dp-raw` by copy; raw is immutable. An error record goes to the ledger.
  2. **Canary sweep**: scan the run's parts for `CONDOR-CANARY-` and the AWS key pattern. Any hit fails the stage and raises a `critical` ledger event: it means redaction failed upstream. Nothing from this run is staged.
  3. **Deduplicate**: within the run, on `(account_id, collector, region, resource_id, record_kind, payload_sha256)`. `account_id` is in the key because not every `resource_id` is an ARN - instance IDs, bucket names and synthesized IDs can repeat across accounts, and collapsing two accounts' records into one is a silent loss.
  4. **Append to Iceberg staging tables** (P3-03) through Athena `MERGE` from `raw_records` filtered to the `run_id`.
  5. **Scope flag**: set `in_scope=false` where `payload.dp_scope="excluded"` (P3-04).
- **Idempotency**: running the stage twice for the same `run_id` produces no duplicate rows. Enforce it with a `MERGE` on `(run_id, account_id, collector, region, resource_id, record_kind, payload_sha256)`.

**Acceptance**
- [ ] Integration: the stage completes for the latest daily run, and a second execution with the same `run_id` leaves row counts unchanged.
- [ ] Injecting a fixture part containing a canary into a test run prefix fails the stage with a `critical` event, and no rows are written for that run.
- [ ] `SELECT count(*) FROM stg_records WHERE json_format(payload) LIKE '%CONDOR-CANARY-%'` returns 0.
