Before starting: read `CLAUDE.md`, confirm every dependency is `done` in `tasks/STATUS.md`, run the account guard for any AWS write.

**Goal.** Collection runs on its own, in the right order, with one run ID per cycle.

**Build**
- **Step Functions `dp-sfn-ingest`** (Standard). Input: `{ "cycle": "daily" | "hourly" | "on_delivery", "run_id": optional }`. Generates a ULID `run_id` if absent.
  - **Daily cycle**, in stages. Each stage is a `Map` or `Parallel` of Lambda invokes, with retries (3, exponential backoff) and a catch that records failure and continues. One collector failing never stops the cycle.
    1. `lifecycle`, `organizations`, `config`, `tagging`, `iam`
    2. `cloudformation`, `tfstate`, `tfstate_history`, `ecs`, `eks`, `elb`, `asg`, `rds`, `backup`, `ebs`, `route53`, `param_secret_meta`, `cloudwatch_alarms`
    3. `ssm_inventory` (after `config`), `ecs_taskdefs`, `kubernetes`, `cloudwatch`, `cost_optimization_hub`, `compute_optimizer`, `license_manager`, `wellarchitected`
    4. `codepipeline`, `codebuild`, `codedeploy`, `ecr`, `github`, `jenkins`, `cloudtrail`, `flowlogs`
    5. `image_trace`
    6. Invoke `dp-sfn-stage` (P3-02) with the `run_id`.
  - **Hourly cycle**: `cloudtrail`, `flowlogs`, `github`, `jenkins`, `codepipeline`, `codebuild`, `codedeploy`, `ecr`, then `image_trace`, then stage.
  - **On-delivery cycle**: `cur` only, then stage.
- **EventBridge Scheduler**
  - Daily at 03:00 UTC.
  - Hourly at minute 15.
- **CUR trigger**: an EventBridge rule on S3 `Object Created` events in `condor-cur-<acct>` under the export prefix, debounced by a Lambda that starts at most one on-delivery cycle per hour.
- **Run summary**: the final state writes to `dp-run-ledger` with collectors succeeded, failed and covered-gap counts.

**Acceptance**
- [ ] A manual daily execution completes. Every collector has a ledger row. The execution succeeds even with the `DENIED_REGION` coverage records.
- [ ] Forcing one collector to raise, through an injected env var `DP_FAIL=<name>`, marks only that collector failed; the cycle completes.
- [ ] The schedules exist and are enabled.
